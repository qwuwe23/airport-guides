# 五元机场使用指南

这个仓库整理五元机场的公开使用说明，便于在设备更换、客户端更新或订阅调整时快速找到入口。

## 从哪里开始

1. 在[用户中心](https://www.5airport.uk/#/login)登录账户并查看当前订阅状态。
2. 从账户页面复制完整订阅链接；不要截断、转发或公开保存该链接。
3. 按设备打开对应的[教程中心](https://www.5airport.uk/guides)：Windows、macOS、Android、iPhone/iPad 均有单独说明。
4. 导入后先刷新订阅，再选择节点做短时实际访问测试。

## 使用提示

不同设备、客户端版本和本地网络的实际表现会有所差异。遇到问题时，优先记录客户端名称与版本、网络类型、节点名称、错误提示和发生时间，再结合[故障排查](https://www.5airport.uk/troubleshooting)逐项确认。

套餐、节点和服务说明以[五元机场用户中心](https://www.5airport.uk/)当前页面为准。
